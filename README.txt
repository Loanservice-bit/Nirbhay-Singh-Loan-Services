## Free hosting with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository (for example: `nirbhay-loan-website`).
3. Upload `index.html`, `style.css`, `script.js`, and `profile.jpg`.
4. Open the repository's Settings → Pages.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then Save.
7. GitHub will provide the live `https://YOUR-USERNAME.github.io/nirbhay-loan-website/` address.
